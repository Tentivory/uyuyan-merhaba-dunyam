# Uyuyan Merhaba Dünyam

## Resmi Açıklama (Ciddiye Alınmalıdır)

Bu depo, insanlığın en büyük sorunlarından birine çözüm getirmektedir: **"Merhaba dünya" demenin aceleciliği.**

Geleneksel programlar anında "Hello World" diye bağırır. Bu, küstahça, saygısızca ve tamamen gereksiz bir aceleciliktir. Bu proje, **tembellik sanatını** programlamaya sokar.

### Nasıl Çalışır?
1. Programı çalıştırırsın.
2. Program düşünür. Uzun uzun düşünür. Belki uyur. Belki çay içer.
3. Sonunda, tamamen hak edilmiş bir "Merhaba dünya... sonunda." der.
4. İş biter. Sen de mutlu olursun.

### Özellikler
- Gerçekten çalışır (denedik, uyudu, uyandı, merhaba dedi).
- Rastgele uyku süreleri (1 ile 10 saniye arası, çünkü daha uzun olursa kimse beklemez).
- Türkçe merhaba. Çünkü neden olmasın?
- Abartılı yorumlar.

### Kurulum
```bash
python merhaba.py
```

Eğer Python yoksa, o da senin sorunun.

### Lisans
Bu kodu istediğin gibi kullan, kopyala, değiştir. Ama merhaba demeden önce bir süre bekle, yoksa ruhunu kaybedersin.
